# Phase 1: Database Infrastructure & Scaffolding

## Goal
Establish the backend Go module structure, Docker Compose PostgreSQL 16 container, schema migration tool (`golang-migrate`), and compile-time type-safe database queries via `sqlc` and `pgx/v5`.

## Context & Architectural Invariants
- The backend resides in `backend/` as a monorepo subfolder.
- The PostgreSQL database is the single source of truth.
- All database interactions MUST use `sqlc` generated code with `jackc/pgx/v5`. No active-record ORMs.
- Foreign keys with `ON DELETE CASCADE` ensure referential integrity.
- Primary keys for `topics` and `vocab_items` are deterministic text slugs (matching `itemId` from `vocab-schema.ts`).
- `refresh_tokens` stores `token_hash` (SHA-256), never plain tokens.
- `user_progress` uses composite primary key `(user_id, item_id)` with index on `(user_id, topic_id)`.

## Tests Before (TDD Contract)
Write tests in `backend/internal/store/db_test.go` *before* finalizing application handlers:
1. `TestMigrationsApplyAndRollback`: Apply `000001_init_schema.up.sql` against a test PostgreSQL instance, assert all 5 tables (`users`, `refresh_tokens`, `topics`, `vocab_items`, `user_progress`) and indices exist, then apply `.down.sql` and verify complete cleanup.
2. `TestUserAndRefreshTokenConstraints`: Attempt inserting a user, inserting a valid refresh token hash, attempting duplicate token hash (assert unique violation), and cascade deletion on user delete.
3. `TestVocabReferentialIntegrity`: Insert topic, insert vocab item referencing topic. Attempt inserting vocab item with non-existent `topic_id` (assert foreign key violation).

## Tasks & Implementation Steps
1. **Initialize Go Module**:
   - `mkdir -p backend && cd backend && go mod init engstack/backend`
   - Add core dependencies: `github.com/jackc/pgx/v5`, `github.com/golang-migrate/migrate/v4`, `github.com/google/uuid`.
2. **Setup Docker Compose**:
   - Define `postgres` service with PostgreSQL 16 Alpine, port `5432`, healthcheck (`pg_isready`), and persistent volume.
3. **Author SQL Migrations (`000001_init_schema.up.sql`)**:
   - `users`: `id UUID PRIMARY KEY DEFAULT gen_random_uuid()`, `google_id VARCHAR(255) UNIQUE NOT NULL`, `email VARCHAR(255) NOT NULL`, `name VARCHAR(255) NOT NULL`, `avatar_url TEXT`, `created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()`, `updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW()`.
   - `refresh_tokens`: `id UUID PRIMARY KEY DEFAULT gen_random_uuid()`, `user_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE`, `token_hash VARCHAR(64) UNIQUE NOT NULL`, `expires_at TIMESTAMPTZ NOT NULL`, `revoked_at TIMESTAMPTZ`, `created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()`.
   - `topics`: `id TEXT PRIMARY KEY`, `track VARCHAR(32) NOT NULL`, `title TEXT NOT NULL`, `description TEXT NOT NULL`, `eyebrow TEXT NOT NULL`, `accent VARCHAR(32) NOT NULL`, `level VARCHAR(16)`, `order_index INT NOT NULL DEFAULT 0`, `related TEXT[] NOT NULL DEFAULT '{}'`, `created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()`.
   - `vocab_items`: `id TEXT PRIMARY KEY`, `topic_id TEXT NOT NULL REFERENCES topics(id) ON DELETE CASCADE`, `track VARCHAR(32) NOT NULL`, `term TEXT NOT NULL`, `ipa TEXT NOT NULL DEFAULT ''`, `label VARCHAR(32) NOT NULL`, `meaning TEXT NOT NULL`, `example TEXT NOT NULL`, `example_vi TEXT NOT NULL`, `definition TEXT NOT NULL DEFAULT ''`, `level VARCHAR(16)`, `pos TEXT[] NOT NULL DEFAULT '{}'`, `created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()`.
   - `user_progress`: `(user_id UUID, item_id TEXT)` composite PK, `topic_id TEXT NOT NULL REFERENCES topics(id) ON DELETE CASCADE`, `is_learned BOOLEAN NOT NULL DEFAULT TRUE`, `updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW()`.
4. **Configure `sqlc` & Generate Code**:
   - Write `sqlc.yaml` targeting `pgx/v5`.
   - Write queries for topic listing, topic fetching, vocab bulk insert, user upsert, refresh token operations, and progress manipulation.
   - Run `sqlc generate` to produce type-safe Go structs.

- **Security**: Never commit database passwords or unhashed secrets to git. Always use `.env.example`.
